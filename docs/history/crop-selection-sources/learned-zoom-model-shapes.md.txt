# Spatial-token model shapes

Current [learned-zoom model](modeling/active-spatial-token-model.md#learned-zoom) at the
baseline's 360-pixel canvases (150/360 mm), 300-pixel scout input, 160-pixel context glimpses
and 224-pixel detail glimpses. `K` is the number of kept canvases in the batch, `B` the number of
studies, and `N` the number of detail glimpses: `min(ceil(0.333 × canvases), candidates)` per
study, about 7 in training and 17 at 2× validation images. The shared-crops diagram it replaced is
in the [historical crop-selection sources](history/crop-selection-sources/README.md). Historical
1C changes only the readout and classifier grouping described in
[modeling](modeling/retired-side-and-compartment-variants.md#historical-disease-sharing).

```mermaid
flowchart TD
    Input["Prepared uint8 triplets<br/>[series, padded inputs, 3, 360, 360]"] --> Keep["Slice mask and retained series<br/>Training series dropout 0.20; restore one if empty"]
    Keep --> Aug["Study reflection on uint8, then per-series affine, intensity and noise<br/>Augmented float canvases [K, 3, 360, 360]"]
    Aug --> Down["Antialiased bilinear downsample, normalize<br/>[K, 3, 300, 300]"]
    Down --> Scout["MobileNetV3 scout<br/>Stride 16 [K, 48, 19, 19]; stride 32 [K, 576, 10, 10]"]
    Scout --> Coarse["Stride 32 sampled bilinearly at stride-16 anchors, concatenated<br/>Linear 624→256 [K, 361, 256]"]
    Aug --> Inverse["Canvas augmentation inverse, then reflection inverse<br/>Float32 outside autocast [K, 3, 3]"]
    Inverse --> CoarseGeometry["Scout anchors in canvas pixels: 1.2 · (x + 0.5) − 0.5, stride 19.2<br/>2D canvas xy and visual validity [K, 361]; fail if a study has none"]
    Coarse --> CoarseTokens["+ 1D, 2D, plane, contrast embeddings<br/>Shared LayerNorm → coarse tokens [K × 361, 256]"]
    CoarseGeometry --> CoarseTokens
    CoarseTokens --> Demand["Demand head, float32: softplus(MLP 256→256→12), initially 1<br/>d [K × 361, 12]"]
    Coarse --> Clusters["Detached, L2-normalised pre-embedding features of valid cells<br/>Per-study spherical k-means, 16 clusters, 5 iterations<br/>Centroids [B, 16, 256], cluster per cell [K, 361]"]
    CoarseGeometry --> Candidates["Candidates: valid cells whose 224 px window overflows by < 19.2 px<br/>81 per canvas [K, 81]; footprints 11 × 11 cells<br/>Budget per study: min(ceil(0.333 × canvases), candidates)"]
    Clusters --> Select["Greedy facility location, float32 without gradient<br/>Weights: Σ_t d over valid tokens; coverage 1 in footprint, else 0.5 · relu(cos(footprint mean, centroid))<br/>Marginal gains via 9 × 19 box filters [B, slots × 81]<br/>Gumbel-max on log gain in training, argmax in evaluation, no repeats<br/>Detail glimpses: study, canvas, cell, offset [N]"]
    Demand --> Select
    Candidates --> Select
    Aug --> Context["Centred 336 px window, antialiased to 160 px, normalize<br/>[K, 3, 160, 160]"]
    Aug --> Detail["Integer 224 px windows, top-left floor(anchor − 112 + 0.5)<br/>Zero outside the canvas; normalize [N, 3, 224, 224]"]
    Select --> Detail
    Context --> ContextCNN["ReXNet-200 forward_features [K, 2560, 5, 5]<br/>Linear 2560→256 [K, 25, 256]"]
    Detail --> DetailCNN["ReXNet-200 forward_features [N, 2560, 7, 7]<br/>Shared linear 2560→256 [N, 49, 256]"]
    Inverse --> GlimpseGeometry["Token anchors in canvas pixels (context origin 12.55, stride 67.2; detail offset + 32 k)<br/>Own visual validity; nearest scout cell [K, 25] and [N, 49]"]
    Select --> GlimpseGeometry
    ContextCNN --> ContextTokens["+ context scale, nearest cell 2D, canvas 1D, plane, contrast<br/>Shared LayerNorm → context tokens [K × 25, 256]"]
    DetailCNN --> DetailTokens["+ detail scale, nearest cell 2D, canvas 1D, plane, contrast<br/>Shared LayerNorm → detail tokens [N × 49, 256]"]
    GlimpseGeometry --> ContextTokens
    GlimpseGeometry --> DetailTokens
    CoarseTokens --> Pool["Attention MLP 256→128→12 on all tokens<br/>Detail logits + log mean demand (with gradient) over the glimpse's valid footprint cells<br/>Mask: study and visual validity [B, 1, K × 361 + K × 25 + N × 49]<br/>One float32 softmax per study and label → pool [B, 12, 256]"]
    ContextTokens --> Pool
    DetailTokens --> Pool
    Demand --> Pool
    Pool --> Head["Twelve independent classifier vectors and biases<br/>12 study logits → BCE"]
    Pool --> Shares["Validation: attention share per group [B, 3, 12]<br/>val_attention_share_coarse, _context, _detail"]
    CoarseTokens --> Draft["Validation: same attention and head on coarse tokens alone<br/>Draft logits [B, 12], logged as val_draft_macro_auc"]
```
