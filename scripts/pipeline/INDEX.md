# Pipeline

The maintained prepare, train, predict, export and submit path. The bundle notebook template `inference.ipynb` is read by `export.py`. Run a script with `--help` for its options, and search `docs/` for its path to find procedures and findings.

Generated by `python -m scripts.tools.script_index write`; change the scripts' CLI descriptions, not this file.

| Script | Purpose |
|---|---|
| [export.py](export.py) | Export one or more scored training checkpoints as an atomic, portable inference bundle and notebook; several checkpoints are averaged as an ensemble |
| [predict.py](predict.py) | Predict complete studies with a repository checkpoint or an exported bundle, spreading them across independent GPU processes |
| [predict_worker.py](predict_worker.py) | Predict one study partition on one device for the prediction coordinator |
| [submit.py](submit.py) | Version a private bundle dataset, run the offline Kaggle notebook, verify its output and submit that exact notebook version, in the foreground |
| [train.py](train.py) | Train the experiment on its selected folds and save validation predictions. A dotted flag overrides that field of the YAML; the defaults and required marks shown are the schema's, not the YAML's |
