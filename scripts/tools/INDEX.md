# Tools

Maintained supporting commands. Every tool imports and runs against the current code. Run a script with `--help` for its options, and search `docs/` for its path to find procedures and findings.

Generated by `python -m scripts.tools.script_index write`; change the scripts' CLI descriptions, not this file.

| Script | Purpose |
|---|---|
| [autoresearch.py](autoresearch.py) | Validate, run, stop and inspect local autoresearch campaigns and the topic loop (subcommands: start, validate, status, results, backfill-labels, usage, stop, resume, import-ideas, adopt, remove-idea, move-idea, supervise, loop-start, loop-status, loop-stop, loop-resume, loop-supervise, job, calibrate, compare) |
| [autoresearch_watch.py](autoresearch_watch.py) | Monitor the topic loop and its campaigns, or one campaign, without model polling and dispatch bounded Codex repairs for operational failures (subcommands: start, status, stop, watch) |
| [balance_anatomy_targets.py](balance_anatomy_targets.py) | Add anatomy masks until every fold of the split holds the same number, then rebuild the prepared targets: picks studies of the short folds at random, converts the sagittal series with most slices of each, segments the new ones with MRAnnotator on the GPU, and exports the bone volumes, the joint classes and the measurements for the whole set under data/labels/prepared. The existing source folder is left untouched; its images and masks are linked |
| [bench_training_steps.py](bench_training_steps.py) | Time the training and validation steps of a recipe under the real trainer on the GPU: mean wait on the loader and mean step in milliseconds, steps per second, peak memory and the first training losses, with an optional breakdown per function (synchronised timers) or a cProfile dump. Validation limited to a few batches ends on the module's completeness check, which is ignored |
| [check_side_routing.py](check_side_routing.py) | Check the side-routed design's guardrails on a freshly built model and one training batch: shared classifiers, their blindness to the compartment, geometry as the only assignment, routing weights that partition every token among the targets of a shared classifier, zero start of the learned geometry, readers that leave the backbone alone, the allowed loss terms and mirror consistency. Runs on the GPU when one is visible and on the CPU otherwise. Exits non-zero when one fails |
| [compare_fold_runs.py](compare_fold_runs.py) | Compare a candidate fold run with a reference run from saved predictions and checkpoint tensors, with paired report-group bootstrap intervals |
| [diagnose_encoding_usage.py](diagnose_encoding_usage.py) | Measure a spatial-token checkpoint's reliance on its embeddings and planes with paired held-out interventions, without training |
| [download_data.py](download_data.py) | Download and extract the Kaggle MRI archive with bounded disk use and resumable chunks; rerun the same command to resume |
| [free_disk.py](free_disk.py) | Free disk space by fixed rules: delete obsolete checkpoints, export weights of unsubmitted models, regenerable analysis arrays, download chunks and tool caches across every worktree and the home caches, and write a manifest of every deleted and kept path |
| [make_timing_checkpoint.py](make_timing_checkpoint.py) | Rebuild the random-weights timing checkpoint for the current preprocessing identity, so a Kaggle timing bundle can be exported |
| [meniscus_targets.py](meniscus_targets.py) | Build meniscus masks from the 3D DESS series with aagatti/nnunet_knee, one step per subcommand (subcommands: convert, segment, export) |
| [plot_validation_metrics.py](plot_validation_metrics.py) | Plot epoch validation metrics from one or more experiment run folders |
| [predict_teacher_table.py](predict_teacher_table.py) | Write the teacher table of a distillation: each teacher run's joint and single-view logits for the studies of its validation fold, at x6 with reflection TTA and attention temperature 0.85 |
| [prepare_codecs.py](prepare_codecs.py) | Download the pinned offline wheels (DICOM codecs, pydantic-settings) for the Kaggle Python runtime |
| [prepare_combined_labels.py](prepare_combined_labels.py) | Build the combined_v1 label table (Steven v4 plus a nine-source consensus mean for ACL, MCL, PF OA and Fracture) and its pinned manifest |
| [prepare_image_blend_labels.py](prepare_image_blend_labels.py) | Build the image_blend_v1 label table (half combined_v1, half the mean out-of-fold predictions of the 2026-09-18 ReXNet-200 and EfficientNet-B0 five-fold runs) and its pinned manifest |
| [prepare_lateral_oa_blend_labels.py](prepare_lateral_oa_blend_labels.py) | Build a Lateral OA blend training-label table: a fixed half public-source, half combined_v1 blend for silver Lateral OA only, preserving gold rows and other targets |
| [prepare_oof_blend_labels.py](prepare_oof_blend_labels.py) | Build the oof_blend_v2 label table (half rebuild_state_v2, a quarter each the x4 out-of-fold predictions of the Refined ResNet-50 and ReXNet-200 five-fold runs of 2026-10-03) and its pinned manifest |
| [prepare_rebuilt_labels.py](prepare_rebuilt_labels.py) | Rebuild all twelve training-label targets from lineage-level public report sources and JevK5 attributes on a common state scale: rebuild_state_v2 (anchored Dawid-Skene report states with a pooled gold semantic calibration) and rebuild_mean_v2 (family-mean control), with cross-fitted gold evaluation |
| [preview_augmentations.py](preview_augmentations.py) | Render study-coherent reflection and other augmentations with source geometry for browsing, with optional CUDA profiling of the reflection |
| [profile_kaggle_inference.py](profile_kaggle_inference.py) | Profile a frozen inference bundle over fold studies in Kaggle notebooks, one per runtime condition (subcommands: launch, analyze) |
| [report_side_routing.py](report_side_routing.py) | Read a finished side-routed run against the campaign base, the best of the lineage and the same-fold sibling runs: per-target deltas with the sibling range, the routed targets' sum, compartment localisation, the side head, the learned geometry, the guardrail flags and whether the run joins the lineage |
| [repredict_run.py](repredict_run.py) | Derive a new run directory whose selected checkpoint's validation predictions are remade at another image multiplier, at attention temperature 1 |
| [script_index.py](script_index.py) | Generate the pipeline and tools script indexes from each script's CLI description and check all script indexes (subcommands: write, check) |
| [serve_campaign_monitor.py](serve_campaign_monitor.py) | Serve one auto-refreshing site for every registered autoresearch campaign: a front page listing the live ones whatever their status, and per campaign its state, the decided runs against the control, per-epoch validation AUC and loss curves of the control, the incumbent and the current run, per-label deltas and its own message box, regenerated on each page request |
| [submission_job.py](submission_job.py) | Launch a detached submission service or inspect its record and runner log (subcommands: start, status, logs) |
| [train_overnight.py](train_overnight.py) | Run the queued ResNet-18 experiments against a saved control run on the control config's fold and seed within a five-hour budget |
| [update_submission_ledger.py](update_submission_ledger.py) | Rebuild the submission ledger from the live Kaggle list and local bundles, and retitle every submission's notebook and bundle dataset in the unified format |
| [validation.py](validation.py) | Create the validation folds or score out-of-fold predictions (subcommands: prepare, score) |
| [verify_inference.py](verify_inference.py) | Check real-study parity, FP32 inference memory and example output of an exported bundle using the bundle's own source |
